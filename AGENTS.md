# Eve Trading Agent Template

Read the installed `node_modules/eve/docs/` guides before changing agent code and `node_modules/next/dist/docs/` before changing Next.js code. Check `eve registry search` before adding integrations.

Keep this a standalone, single-owner Photon/Coinbase template. Never copy production credentials, deployment links, watchlists, schedules, or personal data from Adaam. Financial writes must retain principal authorization, exact preview binding, explicit approval, and replay protection. Test with fixtures; never send a real message, place a trade, or publish a public artifact as a verification step.

Run `npm run check` and `npm run build` before shipping.
